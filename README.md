# shuhari

everyone starts as a beginner. and we all want to get better. i mean ordinary people, like me.

**just start.** follow someone's teaching, a set of rules, exactly as it is. do it until it becomes second nature. the skills here started that way too. i carried over the worlds of the people i call my teachers, exactly as they were.

**second nature is where questions begin.** can you see the essence of what feels obvious now, and where it no longer fits? hold it against other teachers and your own situation. where the rule stops serving the essence, break it. the skills here are waiting for that.

**then outgrow them.** a day comes when you no longer reach for the rules, because what they protected now lives in how you work. say it in your own words, and that is your identity. just don't forget where it came from. the skills here will be rewritten that way, in mine.

## install

```bash
git clone https://github.com/choi-hoseok/shuhari.git
claude --plugin-dir ./shuhari
```

skills are namespaced: `/dojo` is `/shuhari:dojo`.
run `/shuhari:ki` once to choose which models each role uses.
